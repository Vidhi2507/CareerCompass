# CareerCompass
CareerCompass is an AI-powered platform that analyzes a user's resume, identifies skill gaps, recommends target career roles, generates personalized learning roadmaps, conducts AI mock interviews, recommends courses and jobs, and tracks career growth through interactive dashboards.

### Key Features
1. Resume Analysis
2. Skill Gap Analysis
3. Career Recommendation and Personalized Learning Roadmap
4. AI Mock Interview
5. GitHub Project Evaluator (MCP)
6. Analytics Dashboard

 ### Tech Stack
**1. Frontend**
- React
- Tailwind CSS

**2. Backend**
- FastAPI
- LangGraph
- LangChain
- Groq LLM
- Pydantic

**3. Database**
- MongoDB
- Qdrant Vector Database
